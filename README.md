# HORAS CONCEPT — Maquette React

Site vitrine (8 pages) pour validation visuelle avant intégration WordPress / Elementor / Hello.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

Build Coolify : dossier `dist` (SPA statique). Configurer le reverse-proxy pour renvoyer `index.html` sur toutes les routes.

## Identité

- Audiowide (`HORAS`) + Poppins (corps et `concept`)
- `#265db6` · `#FFFFFF` · `#111920`
